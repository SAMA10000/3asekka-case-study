## Core product flow

Production UI evidence prepared from the project source archive includes:

- Vehicle selection
- Order details
- Real-time driver bidding
- Live trip tracking
- Customer home

The full-resolution screenshot pack is maintained privately with the project owner. The public repository intentionally avoids shipping runnable application code or sensitive implementation material.

## OCR / AI verification

See the OCR and anti-manipulation flow diagram in the repository root: `3asekka_ocr_antifraud_flow_colored.png`.

The documented production flow covers OCR, face detection, vehicle/object detection, cross-document consistency checks, duplicate-image protection, confidence-based review, and final human admin approval.
