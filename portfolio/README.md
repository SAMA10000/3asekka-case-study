# 3ASEKKA AI Transport Agent — Portfolio Showcase

> **Portfolio / hackathon showcase. View-only. Production source and private business logic are not published.**

## What I built

3ASEKKA AI Transport Agent adds a natural-language and voice entry point to the existing 3ASEKKA goods-transport workflow.

A customer can describe a transport request in Egyptian Arabic. The agent extracts the operational details, asks only for missing information, recommends a suitable vehicle, estimates a fare, prepares the transport request, and moves the customer into a driver-bidding flow where offers can be compared and selected.

## Why it matters

The project demonstrates practical AI orchestration rather than a standalone chatbot:

**Voice/Text → AI understanding → transport tools → vehicle selection → route/fare → driver bids → offer selection**
