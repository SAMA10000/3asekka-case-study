# 3ASEKKA AI Transport Agent — Live Demo

## Open the deployed agent

**https://3asekka.com/ai-agent/**

This is the public hackathon / portfolio deployment of the 3ASEKKA AI Transport Agent.

### Suggested test

```text
عايز أنقل 20 كرتونة من سموحة للمنشية بكرة الساعة 3، وزنهم حوالي 250 كيلو والمسافة 12 كم
```

### What to expect

1. The agent understands the Arabic transport request.
2. It extracts pickup, destination, cargo, weight and timing.
3. It recommends a suitable vehicle.
4. It shows an estimated fare when route distance is available.
5. Driver offers appear in the bidding workflow.
6. The customer can select an offer.

### Voice

In a compatible Chromium browser, press **🎤 قول طلبك** and speak naturally in Egyptian Arabic.

### Public-demo boundary

This deployment is for hackathon review and portfolio demonstration. Production secrets, private user/driver data, signing keys, and the full private production backend are not exposed.
