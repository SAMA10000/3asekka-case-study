## What this demonstrates

3ASEKKA AI Transport Agent turns a natural Egyptian Arabic goods-transport request into a structured transport workflow.

The user can type or speak a request, the agent extracts the transport details, asks only for missing information, recommends a suitable vehicle, estimates the fare, prepares the transport request, and moves the customer into a driver-bidding flow where offers can be compared and selected.

## Where it fits in the app

This AI experience is designed as an easier way to create a transport request inside the existing 3ASEKKA customer app:

Customer Home  
→ **اطلب بالكلام أو الصوت**  
→ AI understands the request  
→ Customer confirms details  
→ Waiting for Driver Offers  
→ Driver Bidding  
→ Customer selects an offer  
→ Existing 3ASEKKA trip workflow continues
